# Ahrara

Disposable email for AI agents, QA and automation. The relay streams mail to your
computer and keeps no inbox; received mail stays in your encrypted local inbox.

```sh
npm install -g ahrara
ahrara
```

Or run it without installing: `npx ahrara`. Each install downloads only the
executable for its platform (Linux, macOS and Windows on x64 and ARM64) from an
`@ahrara/cli-*` package. `ahrara update` tells npm installations to update with
`npm install -g ahrara@latest`.

See the [documentation](https://ahrara.dev/docs/) and the
[repository](https://github.com/Hitmasu/Ahrara). MIT licensed.
