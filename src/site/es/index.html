Qué es Ahrara, cómo funciona y por qué usarlo

¿Qué es Ahrara?
Direcciones de correo desechables con una bandeja en tu equipo. Lee los mensajes en la terminal o en el navegador, o automatiza con MCP, la API local y los SDK.
¿Cómo funciona?
Ahrara genera las direcciones localmente. Mientras se ejecuta, el servidor transmite los correos entrantes por una conexión cifrada a la bandeja de tu equipo.
¿Por qué usar Ahrara?
Prueba registros, códigos de verificación y plantillas de correo con direcciones dedicadas. Mantén los correos de prueba fuera de tu bandeja personal y deja que tu agente se encargue de las comprobaciones repetitivas.

Cómo usarlo

Lee tu correo en la terminal, pásaselo a tu agente de IA o valídalo desde tus pruebas.

CLI

Instala Ahrara y ejecuta ahrara en tu terminal. Tu dirección de correo se crea automáticamente.

Linux, macOS y Windows en x64 y ARM64.

$brew tap hitmasu/ahrara https://github.com/Hitmasu/Ahrara.git brew install hitmasu/ahrara/ahrara

Pulsa / para abrir los comandos. Mantén Ahrara en ejecución para recibir correos.

Agentes de IA

Instala el plugin de Ahrara y tu agente instalará e iniciará Ahrara por sí mismo. Mediante MCP puede crear direcciones, esperar códigos de verificación, leer mensajes y validar plantillas de correo.

Plugins, reglas y MCP para 25 agentes de programación.

>/plugin marketplace add Hitmasu/Ahrara /plugin install ahrara@ahrara

Ejecútalo dentro de Claude Code y después recarga los plugins. El plugin necesita Node.js 20+.

¿Usas otro agente? Consulta la instalación de agentes para ver todos los hosts compatibles.

SDKs

Da a cada prueba su propia bandeja. Usa su dirección en un flujo de registro o de restablecimiento de contraseña, espera el correo y extrae un código o un enlace. Cada bandeja se conecta directamente al servidor, sin una CLI en ejecución al lado.

Los paquetes incluyen la biblioteca nativa. Validados en Linux x64.

$npm install @ahrara/sdk

Node.js 20+.

Consulta la guía de los SDK para filtros, enlaces, adjuntos y reutilización de bandejas.

Frameworks de pruebas

Crea la bandeja en el setup de tu prueba, usa su dirección en el flujo que pruebas y ciérrala en el teardown.

Usa el SDK desde el framework que ya utilizas.

$npm install @ahrara/sdk

Gestiona la bandeja en un fixture de prueba de Node.

Las mismas API funcionan con xUnit, NUnit, MSTest, pytest y JUnit, y con Selenium mediante el SDK de Java.

Cero retención de datos

El servidor de Ahrara no guarda correos ni registros de direcciones. Su diseño sin estado mantiene la entrega simple, sin una bandeja en el servidor que mantener.

Preguntas frecuentes

¿Ahrara guarda mis correos o direcciones en sus servidores?

No. Los mensajes pasan por el servidor sin guardarse, y las direcciones de correo no se registran allí. Tu bandeja y tus direcciones se guardan localmente en tu equipo.

¿Puedo enviar correos con Ahrara?

No. Ahrara solo recibe correos. No permite enviar mensajes ni responderlos.

¿Ahrara es un relay de correo abierto?

No. Los remitentes pueden entregar correo sin iniciar sesión, pero Ahrara nunca lo reenvía a servidores de correo externos. Los mensajes solo llegan al cliente Ahrara autenticado de la dirección de destino.

¿Puedo usar mi propio dominio?

Sí. Configura el reenvío desde tu dominio a una dirección de Ahrara y después añade el dominio en Ahrara. Las direcciones nuevas usarán tu dominio en lugar de ahrara.dev. Consulta la guía de dominios propios para ver cómo configurarlo.
