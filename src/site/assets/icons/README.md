# Icon sources

- `codex.svg`: OpenAI's unmodified white Blossom from
  [the official logo archive](https://cdn.openai.com/brand/openai-logos.zip),
  linked by the [OpenAI brand guidelines](https://openai.com/brand/).
  The OpenAI logo belongs to OpenAI and identifies the Codex integration.
- `mcp.svg`: the unmodified [official MCP favicon](https://github.com/modelcontextprotocol/docs/blob/573dc60c2e7aab2605b29d0bf27194aa7b02e4fb/favicon.svg).
  CSS inverts its black strokes for the dark background. License reproduced below.
- The remaining small SVGs are local illustrations for the installation methods.

No icon is fetched from a third party at runtime.
